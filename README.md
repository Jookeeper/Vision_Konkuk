# 영유아 위험 물체 감지 시스템 (Capstone Vision)

본 프로젝트는 비전(Vision) 시스템을 활용하여 영유아 주변의 물체를 인식하고, 각 물체의 위험도에 따라 로봇 시스템이 적절히 개입하고 알림을 발생시키는 스마트 안전 모니터링 시스템입니다.

## 📌 `Db.py` (위험도 차등 대조 테이블)

이 시스템의 핵심 판단 기준은 `Db.py`의 `RISK_DATABASE`에 정의되어 있습니다. 비전 모델이 특정 객체를 감지했을 때, 로봇과 알림 시스템이 어떻게 동작해야 하는지를 단계별로 매핑한 모의 데이터셋입니다.

### 🚨 위험도 등급 (Risk Levels)

사물은 아이에게 미치는 위험성에 따라 3단계로 분류됩니다.

- **Lv. 3 긴급 (최고 위험)**

대상 물체: 단추형 건전지, 자석 등 치명적인 피해(장기 괴사 등)를 유발할 수 있는 고위험 물질입니다.

시스템 동작 (즉시 물리적 개입): 시스템 최우선 순위로 처리되며, 탐지 즉시 로봇 자체의 강력한 사이렌을 가동합니다. 동시에 아이의 동선을 파악하여 위험물 사이의 궤적을 선점 주행한 뒤, 물리적으로 해당 물체를 덮거나 밀어내어 사전에 치워버리는 능동적 제거(Active Removal)를 수행합니다.

- **Lv. 2 주의 (경고)**

대상 물체: 동전, 레고 부품 등 기도 폐쇄 우려가 있는 소형 물체입니다.

시스템 동작 (선제 제거 및 푸시 알림): 긴급 사이렌 대신 부모의 스마트폰 앱으로 주의 푸시 알림을 조용히 전송합니다. 이와 동시에 주행/제어 파트로 물체의 실시간 좌표 플래그(REMOVE)를 전송하여 로봇이 알아서 선제적으로 물건을 치우도록 유도합니다.  단, 아이가 이 장난감을 집어 입으로 가져가는 돌발 상황(HOI 알고리즘 추적)이 포착될 때에만 예외적으로 최고 단계의 경고 알람(EMERGENCY_STOP)을 발송합니다.

- **Lv. 1 관심 (안전)**

대상 물체: 크기가 커서 삼킬 위험이 없는 일반 장난감입니다.

시스템 동작 (단순 모니터링 및 돌발 행동 연동): 평상시에는 일상생활에 방해를 주지 않기 위해 개입 없이 시스템에 행동 로그 기록만 남기며 관찰(MONITOR)합니다. 단, 아이가 이 장난감을 집어 입으로 가져가는 돌발 상황(HOI 알고리즘 추적)이 포착될 때에만 예외적으로 최고 단계의 경고 알람(EMERGENCY_STOP)을 발송합니다.

- **예외 상황 처리**
우선 순위 할당 : 한 공간 안에 레벨이 다른 물체 놓이면 높은 거부터 처리하는 방식으로
도달 시간 기반 : Lv3은 아이와 떨어져있고, 당장 Lv2가 아이의 입에 가는 경우는 후자를 먼저 처리 (강제 오버라이드)
인식이 어려워서 임계치보다 낮은 경우 -> 무조건 더 높은 위험도로 간주해서 처리

## ⚙️ 데이터베이스 구조 상세

`RISK_DATABASE`는 Python 딕셔너리 형태로 구성되며 각 감지된 객체명(Key)에 대해 다음과 같은 설정값(Value)을 포함합니다.

- **`level`** (int): 시스템 내부의 위험도 처리 우선순위 (1~3)
- **`status`** (str): UI/시스템 로그에 표출될 상태 텍스트 (위험, 주의, 관심)
- **`robot_action_cmd`** (str): 카메라에 객체가 감지되었을 때 로봇이 취할 행동
  - `REMOVE`: 아이가 접근하기 전 로봇이 해당 물체를 선제적으로 치움
  - `MONITOR`: 별도 개입 없이 상황을 지켜봄
- **`mouth_action_cmd`** (str): 아이가 물체를 입으로 가져가는 제스처가 인식되었을 때의 대응
  - `EMERGENCY_STOP`: 즉시 급정지 및 비상 사이렌 가동
  - `ALARM`: 일반적인 위험 경고음 발생
- **`msg`** (str): 시스템 콘솔이나 보호자 알림 앱으로 전송될 상세 상황 메시지

## 🚀 시스템 동작 플로우 (예상)

1. **객체 감지**: 비전 카메라가 아이 주변의 물체(`Car`, `Panda` 등)를 인식합니다.
2. **데이터 매칭**: 감지된 객체 이름을 `Db.py`의 `RISK_DATABASE`에서 조회합니다.
3. **초기 대응**: `robot_action_cmd`를 읽어 로봇을 즉시 이동시켜 선제거할지, 감시만 할지 결정합니다.
4. **위험 제스처 감지**: 아이가 물체를 집어 입으로 향하는 행동이 포착되면 `mouth_action_cmd`에 따라 경고(`ALARM`)를 울리거나 비상 정지(`EMERGENCY_STOP`)를 수행하여 사고를 미연에 방지합니다.
